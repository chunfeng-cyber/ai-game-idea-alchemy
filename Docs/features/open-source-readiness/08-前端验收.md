## 文件职责

- `public/alchemy-source.html` 仅保留页面结构与静态资产引用，约 11 KB，不再夹带图集 base64、CSS 或交互代码。
- `alchemy-ui.css` 管理原桌面构图和窄屏可滚动布局；`alchemy-security.js` 统一 URL、宿主消息、报告及草稿校验。
- `alchemy-catalog.js` 保存静态材料目录；实时来源仍由服务查询并单独合并。
- `alchemy-art-assets.js` 隔离既有图集字节，素材授权另见 ASSETS.md；移除启动时立即清空的重复隐藏示例图，不改当前显示图集。
- `alchemy-app.js` 管理材料交互、实时热点、报告、草稿恢复及任务状态；`alchemy-model-settings.js/.css` 管理独立 API 设置和维护入口。
- `worker/alchemy-mcp.mjs` 用同一组公开文件内联生成 MCP 资源，本地与宿主共用实现；不再依赖 Vite 的 `?raw` 导入。

## 交互与安全

- 失败响应里的合法草稿显示“继续生成海报”；已有结果旁也可继续新的草稿。继续请求只包含 draftId、sourceDraftVersion、requestId，不重复发送合成提示词。
- `GET /api/result` 恢复完成报告后，再 `GET /api/draft` 恢复未完成方案；异步回复用 epoch 防止覆盖更新结果。409 时清理旧身份并获取最新草稿。
- 图片完成、排版失败的草稿按钮显示“继续排版海报”；成功后清草稿入口、展示新海报。重绘旧完成结果保持单独含义。
- 窄屏采用纵向单列和原生滚动，保留 720×405 桌面画布。触屏点击材料即可加入，避免自定义拖动吞掉纵向滚动；鼠标仍可拖入锅。
- 模型设置添加中文字体状态、图片清理预览和独立“确认清理”按钮。只有已预览 planToken 才可提交；预览变化或失败必须重新预览；不自动删图。
- 非本机页面和宿主不读取用户 localhost 热点、报告、草稿或设置；宿主实时检索使用当前对话能力。

## 静态资源缓存纠错

真实浏览器发现旧版本 `/alchemy-model-settings.js` 已被缓存：磁盘文件已更新，但页面仍执行旧脚本，缺少维护和字体入口。源码的 7 个 CSS/JS 引用加入本次发布版本；生产构建依据每个资产的 SHA256 自动生成 `?v=<内容 hash>`，今后任何脚本或样式变化都会改变 URL。未变化的资产版本保持稳定，不依赖用户强制刷新。

MCP 内联与测试辅助器按文件路径查找资产，忽略版本查询，因此版本化资源仍保持完全自包含。新增 3 项回归验证源码引用、变化与稳定内容版本、真实 MCP 资源全部内联；28 项前端定向检查通过。新版构建成功，随后 20 项资源版本、安全、渲染与 MCP 检查全部通过。

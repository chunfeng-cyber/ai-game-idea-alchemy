现状问题修订验收

热点Windows请求与其他平台请求分别缓冲全部内容，字节限制与重定向边界不一致。独立网络模块，最多2MB，统一超时，UTF8流边界解码，公开HTTPS域名白名单，每次重定向重新校验；保留官方来源与真实日期。拒绝内网/HTTP/凭证/未知主机/恶意跳转，拒绝超大分块响应，真实全球刷新并记录全部来源。
生成图不断增长，无清理入口。仅显式预览后清理30天前的可识别生成PNG，保留当前结果与草稿引用、近期和不认识的文件。计划变化时要求重新预览；生成与清理互斥。临时目录真实清理，仅删除预览文件；拒绝过期计划，当前结果/草稿/配置保持。

配置与交互

ALCHEMY_FONT_FILE 指向用户有权使用的TTF/OTF/TTC/OTC文件，ALCHEMY_FONT_FAMILY 可指定字体家族。没有系统CJK时明确失败，避免把缺字图交给用户。

模型设置里的维护入口先GET /api/maintenance展示待清理数量和大小，再由用户确认并POST /api/maintenance/cleanup携带planToken。应用不自动删除历史图片，也不清理密钥和运行结果。

全球热点仍是公开数据能力。来源限流、日期未发布或渠道未接入必须显示真实状态；本轮网络成功不能变成永久可用承诺。

模块边界

worker/chinese-font.mjs供海报和旧卡片共享；worker/trend-network.mjs供sidecar公开热点读取；worker/runtime-retention.mjs仅管理受保护图片；HTTP、设置和交互沿现有模块接入。源码发行包不得包含生成图、runtime或作者配置。
